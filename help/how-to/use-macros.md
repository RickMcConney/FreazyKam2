# Save G-code as a macro

Keep commands you use often one click away.

1. In the Machine tab sidebar, under **Macros**, click **Add**.
2. Type a name.
3. Type the G-code, one command per line.
4. Save.

Click the macro to send it. Hover for **Edit** or **Delete**.

Macros can't run during a job. STOP or a lost connection ends a macro.
