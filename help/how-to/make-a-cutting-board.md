# Make a cutting board

1. Open the shape picker and click **Board**.
2. Set:

   | Field | Options |
   |---|---|
   | **Shape** | Rectangle · Oval · Barrel |
   | **Width**, **Height** | Board size |
   | **Handle** | None · Paddle · Side slots · End slot |
   | **Hole** | Tick for a hanging hole, then set **Hole Ø** |
   | **Groove** | Tick for a juice groove, then set **Inset** |

3. Place it.
4. **Double-click** it to split it into separate paths.
5. Cut each part with its own operation:

   | Part | Operation | Tool |
   |---|---|---|
   | Outline | Profile, outside | End mill |
   | Juice groove | Profile, centerline | Ball nose |
   | Hand slots | Pocket | End mill |

Features that don't fit are moved or left out. Check the canvas.
