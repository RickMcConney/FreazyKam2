# Change speed during a job

Under the job box in the Machine tab sidebar:

| Control | Do |
|---|---|
| **Feed** | **‹** / **›** change by 10 %. **↺** back to 100 % |
| **Rapid** | Pick 25, 50 or 100 % |
| **Spindle** | Like Feed (VFD spindles only) |
| **Router** | Shows the dial number to set by hand |

Anything not at 100 % shows in blue. The limit is 10–200 %.
