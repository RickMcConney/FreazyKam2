# Add a tool

1. Click the **Tool Library** tab above the canvas.
2. Click the **My Tools** folder tab.
3. Click **Add Tool**.
4. Fill in at least:

   | Field | Enter |
   |---|---|
   | Name | What you call it in the shop |
   | Type | End Mill, Bull Nose, Ball Nose, V-bit, Taper End Mill or Drill |
   | Ø | Cutting diameter (**tip** diameter for a taper) |
   | Flutes | Number of cutting edges |
   | Max Z | Usable cutting length |
   | Angle° / R | V-bit: **included** angle. Taper: angle **per side**. Bull nose: corner radius |

5. Optional: enter the maker's **Chip** load rating.

The small picture in the row is drawn from your numbers. Check it looks like your bit.

**Tool missing from an operation?** It's the wrong type for that operation. See
[which tools each operation uses](../reference/tools.md#which-operations-offer-each-type).
