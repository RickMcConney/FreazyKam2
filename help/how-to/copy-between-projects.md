# Copy parts between projects

1. Select the parts.
2. Press **Ctrl+C**.
3. Open the other project (another tab or window works).
4. Press **Ctrl+V**.

Shapes stay editable: a gear keeps its tooth count, tabs come with their path.
Operations are **not** copied. Make them again in the new project.

## Export as SVG instead

Click **Export SVG** in the toolbar to save outlines for another program. This keeps only
the outlines, not the shape settings.
