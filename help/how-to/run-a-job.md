# Send and run a job

## Send the design you have open

1. In the Machine tab sidebar, click **Send to card**.
2. Check the map. The job should sit inside the stock. A **Runs off the stock** warning means
   it doesn't.

## Or run a file

- **From the card:** click it in the list.
- **From your computer:** click **Upload file**, or drag files onto the list.

## Run

1. [Zero X, Y and Z](home-and-zero.md).
2. Fit the bit the job needs.
3. Start the router.
4. Click **Run**.

A progress bar shows how far through the job you are.

## Run is greyed out?

| Check | Fix |
|---|---|
| X, Y, Z not all ✓ | Zero them |
| No job loaded | Send or click a file |
| Card busy | Wait for upload to finish |

**Related:** [Pause, stop or end a job](stop-a-job.md)
