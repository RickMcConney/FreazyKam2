# Keyboard and mouse

Also listed in the app under the **?** button.

## Files

| Keys | Does |
|---|---|
| Ctrl+N | New project |
| Ctrl+O | Open project |
| Ctrl+S | Save project |

## Editing

| Keys | Does |
|---|---|
| Ctrl+Z / Ctrl+Y | Undo / Redo |
| Ctrl+C / Ctrl+V / Ctrl+X | Copy / Paste / Cut (works between projects) |
| Ctrl+D | Duplicate |
| Ctrl+G | Group |
| Ctrl+Shift+G | Ungroup |
| Delete, Backspace | Delete selected |
| Arrow keys | Nudge 1 mm (0.1"). Shift ×10, Alt ÷10 |
| Esc | Deselect, or cancel the current tool |

## View

| Input | Does |
|---|---|
| Scroll | Zoom |
| Middle-drag, or Space + drag | Pan |
| S | Snap to grid on/off |
| C | Constrain tool |

## Selecting

| Input | Does |
|---|---|
| Click | Select (the whole group if grouped) |
| Shift-click | Add or remove from selection |
| Alt-click | Select one path inside a group |
| Drag right | Select what the box touches |
| Drag left | Select what's fully inside |
| Shift-click (form open) | Add or remove a path from the operation |

## Handles

| Input | Does |
|---|---|
| Drag corner | Resize |
| Drag edge | Stretch one way |
| Drag top handle | Rotate |
| Alt + drag corner | Skew |

## Pen tool

| Input | Does |
|---|---|
| Click | Place point |
| Drag (Bezier) | Pull handles |
| Alt-click | Straight segment |
| Click first point | Close |
| Esc | Finish open |
| Ctrl+Z | Remove last point |

## Point editing

| Input | Does |
|---|---|
| Double-click path | Start editing |
| Click segment | Add point |
| Hover point + Delete | Remove point |
| Alt-click point | Corner ↔ curve |
| Esc | Finish |

## Simulator

| Input | Does |
|---|---|
| Space | Play / Pause |

## Generate

| Input | Does |
|---|---|
| Alt-click Generate | Force a pocket strategy that declined |
